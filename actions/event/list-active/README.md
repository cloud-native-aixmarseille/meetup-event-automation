## Overview

List open meetup issue numbers from the caller repository using the configured event label. Report concise technical facts and diagnostic codes in logs and the job summary.

<!-- overview:end -->
<!-- usage:start -->

## Usage

```yaml
- uses: cloud-native-aixmarseille/meetup-event-automation/actions/event/list-active@c96cf1e15b7a8a824a706582f6ba328374a888df # 2.3.1
  with:
    # Language for generated reports and guidance (en or fr). Regional variants are supported; unsupported locales fall back to English.
    # This input is required.
    locale: ""

    # Token for the caller repository with issues:read permission.
    # This input is required.
    github-token: ""
```
