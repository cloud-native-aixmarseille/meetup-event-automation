## Overview

Reconcile the post-event presentation PDF while preserving its identity, source revision and export recovery state.

<!-- overview:end -->
<!-- usage:start -->

## Usage

```yaml
- uses: cloud-native-aixmarseille/meetup-event-automation/actions/assets/reconcile-slides-pdf@5a80cd5013781ff071bea0dfda49044bc4071c5f # 2.3.2
  with:
    # Language for generated reports (en or fr).
    # This input is required.
    locale: ""

    # GitHub token for reading the consumer repository and event issues.
    # This input is required.
    github-token: ""

    # Meetup issue number.
    # This input is required.
    issue-number: ""

    # Public asset identities and issue revision emitted by document reconciliation.
    # This input is required.
    pdf-source: ""

    # Whether the prepared presentation content is ready.
    # This input is required.
    slides-ready: ""

    # Service-account JSON with access to the presentation and public PDF folder.
    # This input is required.
    google-credentials: ""

    # Shared public destination folder for PDFs.
    # This input is required.
    google-drive-public-folder-id: ""
```
