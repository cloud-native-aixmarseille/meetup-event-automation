## Overview

Validate referentials and synchronize the public meetup issue form. Invalid records and projection drift are reported without failing CI; technical failures still fail.

<!-- overview:end -->
<!-- usage:start -->

## Usage

```yaml
- uses: cloud-native-aixmarseille/meetup-event-automation/actions/issue-form/reconcile@5a80cd5013781ff071bea0dfda49044bc4071c5f # 2.3.2
  with:
    # Language for generated reports and guidance (en or fr). Regional variants are supported; unsupported locales fall back to English.
    # This input is required.
    locale: ""

    # Use check to detect projection drift or fix to rewrite the checked-out issue form with the validated public projection.
    # This input is required.
    mode: ""
```
