## Overview

Select the active feedback event across the repository and reconcile the existing shared Kutt link.

<!-- overview:end -->
<!-- usage:start -->

## Usage

```yaml
- uses: cloud-native-aixmarseille/meetup-event-automation/actions/feedback/reconcile-short-link@5a80cd5013781ff071bea0dfda49044bc4071c5f # 2.3.2
  with:
    # Language for generated reports (en or fr).
    # This input is required.
    locale: ""

    # GitHub token for reading the consumer repository and event issues.
    # This input is required.
    github-token: ""

    # HTTPS base URL of the Kutt instance.
    # This input is required.
    kutt-base-url: ""

    # Existing Kutt link API ID.
    # This input is required.
    kutt-link-id: ""

    # API key for the owner of the existing link.
    # This input is required.
    kutt-api-key: ""
```
